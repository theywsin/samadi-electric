Companion plugin for the Samadi Electric theme: 19 Elementor widgets, dynamic tags, product filters, live product search, wholesale / price inquiry requests, recently viewed products and setup tools.

== Description ==

* Works with Elementor (free) and Elementor Pro; every component also has a shortcode.
* Product filters use WooCommerce's native query parameters (shareable URLs, AJAX with history).
* Quote requests are stored privately (WooCommerce → درخواست‌های استعلام) and emailed to the store.
* Works with other themes (loads its own standalone styles).
* HPOS compatible.

Bundled: Lucide icons subset (ISC) — includes/LICENSE-lucide.txt
