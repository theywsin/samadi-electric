طراحی کامل و اختصاصی صفحه «حساب کاربری من» ووکامرس (فارسی و راست‌چین).

== Description ==

* پیشخوان: بنر خوشامد با تصویر، چهار کارت آمار (تعداد سفارش، مجموع خرید، علاقه‌مندی‌ها، آدرس‌ها)، آخرین سفارش‌ها با تصویر کالا، تاریخ شمسی و برچسب رنگی وضعیت، آدرس‌ها، علاقه‌مندی‌ها و اطلاعات حساب.
* ستون کناری: عکس پروفایل، نام و ایمیل، منوی آیکون‌دار و کادر «نیاز به کمک دارید؟».
* دفترچه آدرس چندگانه (خانه، محل کار، سایر) با آدرس پیش‌فرض که با صورتحساب/ارسال ووکامرس همگام می‌شود و انتخاب آدرس در تسویه‌حساب (کلاسیک و بلوکی).
* علاقه‌مندی داخلی با دکمه قلب روی محصولات و صفحه «علاقه‌مندی‌ها» (اگر YITH یا TI Wishlist نصب باشد از همان استفاده می‌شود).
* بارگذاری عکس پروفایل و شماره موبایل در «اطلاعات حساب» (بدون Gravatar و درخواست خارجی).
* فونت وزیرمتن محلی، ارقام فارسی، تاریخ شمسی؛ با هر قالبی کار می‌کند و با قالب صمدی الکتریک یکپارچه است.
* همه هوک‌های ووکامرس حفظ شده‌اند.

تنظیمات: ووکامرس ← طراحی حساب کاربری.

== Installation ==

1. افزونه‌ها ← افزودن ← بارگذاری افزونه: فایل samadi-account.zip
2. فعال‌سازی. (پیوندهای یکتا خودکار به‌روز می‌شوند.)
3. ووکامرس ← طراحی حساب کاربری: تصویر بنر و لینک پشتیبانی را تنظیم کنید.
