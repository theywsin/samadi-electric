# گزارش تست‌های انجام‌شده

**محیط:** WordPress 7.1.3، WooCommerce 10.9.4 (از سورس، با ساخت دستی assetهای کلاسیک)، Elementor 3.35.9 (از سورس، بدون build ویرایشگر JS)، PHP 8.3، دیتابیس SQLite (افزونه رسمی SQLite Database Integration)، Chromium (Playwright). داده‌ها: ۱۱ محصول آزمایشی (ساده، متغیر ۴ رنگ، تخفیف‌دار، ناموجود، قیمت با استعلام)، ۵ برند، ۷ دسته، کوپن ۱۰٪. این داده‌ها فقط در سایت تست بودند و همراه قالب/افزونه ارائه نمی‌شوند.

## موارد تست‌نشده (به‌خاطر محدودیت محیط)

- **Elementor Pro / Theme Builder**: Elementor Pro در دسترس نبود. ویرایشگر Elementor رایگان در نسخه ۱٫۱ تست شد؛ کشیدن‌ورها کردن دستی ویجت‌ها با ماوس تست نشد (ویرایش از طریق API خود ویرایشگر انجام شد).
- **Cart/Checkout Blocks** ووکامرس (نیازمند build جاوااسکریپت بلوک‌ها).
- **درگاه‌های پرداخت آنلاین ایرانی، ایمیل واقعی، افزونه‌های علاقه‌مندی/مقایسه، Yoast/Rank Math** — کد یکپارچگی نوشته شده ولی با خود افزونه‌ها اجرا نشد.
- **MySQL/MariaDB**: تست روی SQLite انجام شد؛ کوئری‌های فیلتر استاندارد و سازگار با MySQL هستند.
- ترجمه فارسی رسمی وردپرس/ووکامرس در محیط تست نصب نبود (متن‌های خود ووکامرس انگلیسی دیده می‌شد؛ گزینه «همیشه راست‌چین» قالب RTL را تضمین کرد).
