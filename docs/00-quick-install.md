# نصب سریع (کمتر از ۵ دقیقه)

1. **نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته**: فایل `samadi-electric.zip` را نصب و فعال کنید.
2. در اعلان بالای پیشخوان روی **«نصب و فعال‌سازی Samadi Core»** کلیک کنید.
   (یا `samadi-core.zip` را از «افزونه‌ها ← افزودن ← بارگذاری» نصب کنید.)
3. راه‌انداز «صمدی الکتریک» باز می‌شود؛ روی **«شروع راه‌اندازی کامل»** کلیک کنید.
   - WooCommerce و Elementor از مخزن وردپرس نصب و فعال می‌شوند (هاست باید به wordpress.org دسترسی داشته باشد).
   - افزونه Samadi Elementor Widgets از بسته همراه نصب می‌شود.
   - دموی کامل درون‌ریزی می‌شود.

پس از پایان، این موارد آماده‌اند و نیازی به ساختن دستی ندارند:

| بخش | محتوا |
|---|---|
| صفحه اصلی | Elementor با بنر ۳ اسلایدی، دسته‌ها، مزایا، پیشنهاد ویژه، پرفروش‌ها، جدیدترین‌ها، برندها، مقالات |
| فروشگاه | ۲۷ محصول (ساده، متغیر رنگی، تخفیف‌دار، ناموجود، استعلامی) با تصویر، گالری، ویژگی فنی و نظر |
| طبقه‌بندی | ۷ دسته اصلی + زیردسته با تصویر، ۵ برند با لوگو، ۸ ویژگی (رنگ با کد رنگ) |
| برگه‌ها | سبد، تسویه، حساب کاربری، خرید عمده (فرم استعلام)، درباره ما، تماس با ما، سؤالات متداول، رویه ارسال و مرجوعی، قوانین، حریم خصوصی، مجله (وبلاگ) |
| وبلاگ | ۶ مقاله با تصویر شاخص در ۳ دسته |
| منوها | هدر، موبایل، فوتر (دسته‌ها + راهنما) |
| ابزارک‌ها | فیلتر محصولات فروشگاه، سایدبار وبلاگ |
| تنظیمات | تومان، ایران، پیوند یکتا، ارسال (پیشتاز + رایگان بالای ۵ میلیون)، پرداخت در محل و کارت‌به‌کارت، رنگ‌ها و فونت Elementor |

**پس از نصب:** اطلاعات تماس، شبکه‌های اجتماعی و نام برندها نمونه‌اند؛ از «سفارشی‌سازی ← صمدی الکتریک» و «محصولات ← برندها» جایگزین کنید.
حذف کامل دمو: «صمدی الکتریک ← حذف محتوای دمو».

نصب از خط فرمان (WP-CLI):

```bash
wp theme activate samadi-electric
wp plugin install samadi-core.zip --activate
wp samadi plugins --user=admin
wp samadi import --user=admin
```
