# تنظیمات WooCommerce

- **ووکامرس ← تنظیمات ← عمومی**: واحد پول «Iranian toman (تومان)»، جایگاه «راست با فاصله»، تعداد اعشار ۰، جداکننده هزارگان «,». کشورهای فروش: ایران.
- **محصولات ← موجودی**: مدیریت موجودی فعال؛ در صورت تمایل «پنهان کردن کالاهای ناموجود». رفتار خرید کالای ناموجود و پیش‌سفارش کاملاً از همین تنظیمات خوانده می‌شود.
- **محصولات ← برندها** (ووکامرس ۹٫۶+): برندها را با لوگو تعریف کنید؛ کارت‌ها، فیلتر، بخش برندها و مشخصات فنی از آن استفاده می‌کنند.
- **ارسال**: مناطق و روش‌های ارسال را تعریف کنید.
- **پرداخت**: درگاه‌های فعال؛ قالب هیچ تغییری در فرآیند پرداخت نمی‌دهد.
- **پیشرفته ← تنظیمات صفحه**: سبد، تسویه‌حساب، حساب کاربری. هم صفحات بلوکی (Cart/Checkout Blocks) و هم شورت‌کدی (`[woocommerce_cart]`, `[woocommerce_checkout]`) استایل شده‌اند. اگر از ویجت‌های Elementor Pro برای سبد/تسویه استفاده می‌کنید، صفحه شورت‌کدی (کلاسیک) را ترجیح دهید.
- **ووکامرس ← تنظیمات صمدی**: صفحه استعلام، ایمیل اعلان، نمایش دکمه استعلام، نمایش «استعلام قیمت» برای محصولات بدون قیمت، جستجوی زنده/SKU، noindex صفحات فیلترشده، محصولات اخیر.
- **سفارشی‌سازی ← فروشگاه و کارت محصول**: ستون‌ها، تعداد در صفحه، نمایش SKU/برند/موجودی/امتیاز در کارت، حالت کارت، ستون فیلتر.

## حساب کاربری

بخش «حساب من» طراحی اختصاصی دارد که از زبان طراحی فیگما (نسخه ۲) پیروی می‌کند (`assets/css/account.css`، فقط در صفحه حساب بارگذاری می‌شود):

- **منو**: کارت کاربر (حرف اول نام، نام، ایمیل) و منوی آیکن‌دار؛ در موبایل به نوار افقی قابل اسکرول تبدیل می‌شود. آیکن هر آیتم با فیلتر `samadi_account_menu_icon` قابل تغییر است و آیتم‌های افزونه‌ها هم نمایش داده می‌شوند.
- **پیشخوان**: خوش‌آمدگویی، آمار سفارش‌ها (همه، در حال انجام، تحویل‌شده؛ فیلتر `samadi_account_stats`)، میان‌برها و سه سفارش آخر.
- **سفارش‌ها**: کارت سفارش با برچسب رنگی وضعیت، تصویر کالاها، مبلغ و دکمه‌ها. ستون‌های اضافه‌شده با `woocommerce_account_orders_columns` و callbackهای `woocommerce_my_account_my_orders_column_*` همچنان کار می‌کنند. رنگ وضعیت‌های سفارشی با فیلتر `samadi_account_status_tone` تعیین می‌شود.
- **آدرس‌ها، جزئیات حساب، مشاهده سفارش، ورود/ثبت‌نام**: فقط با CSS استایل شده‌اند و از قالب‌های خود ووکامرس استفاده می‌کنند.

قالب‌های بازنویسی‌شده: `woocommerce/myaccount/navigation.php`، `dashboard.php`، `orders.php`، `my-address.php` (به‌همراه `template-parts/account/`). پس از به‌روزرسانی ووکامرس، اگر در «وضعیت سیستم» قالب‌ها قدیمی گزارش شدند، تغییرات نسخه جدید را با این فایل‌ها مقایسه کنید.
