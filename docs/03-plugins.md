# افزونه‌های ضروری و اختیاری

## ضروری
| افزونه | توضیح |
|---|---|
| WooCommerce | فروشگاه |
| Samadi Elementor Widgets | افزونه همراه (ویجت‌ها، فیلتر، جستجوی زنده، استعلام قیمت) |
| Samadi Core | هسته قالب: علاقه‌مندی‌ها، مقایسه، خبرنامه، تاریخ شمسی، تسویه‌حساب ایرانی، اسکیما و امنیت ([راهنما](11-core-plugin.md)) |
| Elementor (رایگان) | ویرایش صفحات |

## اختیاری
| افزونه | کاربرد | نوع |
|---|---|---|
| Elementor Pro | Theme Builder هدر/فوتر/محصول/آرشیو، برچسب‌های پویا | **پولی** |
| YITH WooCommerce Wishlist یا TI WooCommerce Wishlist | جایگزین علاقه‌مندی‌های Samadi Core (در صورت فعال بودن، قالب از آن‌ها استفاده می‌کند) | رایگان |
| Yoast SEO یا Rank Math | سئو؛ قالب Breadcrumb و Schema آن‌ها را به‌کار می‌گیرد | رایگان |
| افزونه درگاه پرداخت ایرانی سازگار با WooCommerce | پرداخت آنلاین | طبق ارائه‌دهنده |
| افزونه پیامک/ورود با موبایل | احراز هویت | طبق ارائه‌دهنده |
| افزونه تاریخ شمسی (مثل Parsi Date) | جایگزین تاریخ شمسی Samadi Core | رایگان |
| افزونه پرسش و پاسخ محصول | تب پرسش و پاسخ | طبق ارائه‌دهنده |
| افزونه کش (LiteSpeed Cache, WP Rocket …) | سرعت | — |
