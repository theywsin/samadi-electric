# چک‌لیست آزمون فروشگاه

- [ ] صفحه اصلی دسکتاپ و موبایل (بدون اسکرول افقی)
- [ ] جستجوی زنده: نام، SKU، دسته، برند؛ حالت بدون نتیجه؛ کیبورد (↑ ↓ Enter Esc)
- [ ] آرشیو: مرتب‌سازی، تعداد، شبکه‌ای/فهرستی، صفحه‌بندی
- [ ] فیلترها: برند، قیمت، موجودی، رنگ و سایر ویژگی‌ها؛ ترکیب چند فیلتر؛ حذف تکی/همه؛ دکمه بازگشت مرورگر؛ کپی URL
- [ ] موبایل: پنل کشویی فیلتر، بستن با Esc و دکمه
- [ ] کارت محصول ساده (افزودن Ajax)، متغیر (انتخاب گزینه‌ها)، گروهی، خارجی، ناموجود، قیمت با استعلام
- [ ] صفحه محصول متغیر: تغییر قیمت، تصویر، موجودی؛ غیرفعال بودن متغیر ناموجود؛ شناسه متغیر درست در سبد
- [ ] کنترل تعداد +/−، نوار خرید چسبان موبایل
- [ ] سبد: تغییر تعداد، حذف، کد تخفیف، جمع‌ها
- [ ] تسویه‌حساب با هر روش پرداخت فعال، ثبت سفارش، صفحه تشکر
- [ ] حساب کاربری: ثبت‌نام، ورود، سفارش‌ها، جزئیات سفارش، آدرس‌ها، تغییر رمز، خروج
- [ ] فرم خرید عمده: خطاهای اعتبارسنجی، ثبت موفق، ایمیل مدیر، ثبت در «درخواست‌های استعلام»
- [ ] ویرایش صفحه اصلی و ویجت‌ها در Elementor
- [ ] (Pro) هدر/فوتر/محصول/آرشیو Theme Builder با شرط نمایش
- [ ] کیبورد و صفحه‌خوان: Skip link، منوها، مگامنو، کشوها، اعلان افزودن به سبد
