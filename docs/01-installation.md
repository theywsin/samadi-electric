# راهنمای نصب

## مراحل

1. **زبان سایت**: «تنظیمات ← عمومی ← زبان سایت» را «فارسی» کنید تا متن‌های وردپرس و ووکامرس فارسی شوند.
2. **ووکامرس** را نصب و فعال کنید.
3. **قالب**: «نمایش ← پوسته‌ها ← افزودن ← بارگذاری» و فایل `samadi-electric.zip` را نصب و فعال کنید.
4. **افزونه همراه**: «افزونه‌ها ← افزودن ← بارگذاری» و `samadi-elementor-widgets.zip` را نصب و فعال کنید.
5. **Elementor** (و در صورت تمایل Elementor Pro) را نصب و فعال کنید.
6. **ووکامرس ← تنظیمات صمدی ← ابزارهای راه‌اندازی** را اجرا کنید:
   - ساخت ویژگی‌های پیشنهادی (رنگ، مدل، نوع نصب، جنس بدنه، جریان نامی، ولتاژ، توان، سری، IP)
   - ساخت دسته‌بندی‌های اصلی پیشنهادی
   - ساخت صفحه «خرید عمده و استعلام قیمت»
   - ساخت صفحه اصلی با Elementor (گزینه «به‌عنوان صفحه اصلی سایت» را تیک بزنید)
7. **نمایش ← فهرست‌ها**: منوی اصلی را بسازید و به جایگاه «منوی اصلی (هدر)» اختصاص دهید. (اختیاری: منوی موبایل و دو منوی فوتر)
8. **نمایش ← ابزارک‌ها ← فیلترهای فروشگاه**: ابزارک «فیلتر محصولات صمدی» را اضافه کنید.
9. **نمایش ← سفارشی‌سازی ← تنظیمات صمدی الکتریک**: لوگو، رنگ‌ها، اطلاعات تماس واقعی، شبکه‌های اجتماعی، لینک خرید عمده و … .
10. **تنظیمات ← پیوندهای یکتا**: یک‌بار «ذخیره» کنید.

## نکته کش

صفحه خرید عمده (فرم استعلام)، سبد خرید، تسویه‌حساب و حساب کاربری را از کش صفحه مستثنا کنید. سایر قابلیت‌ها (محصولات اخیر، شمارنده سبد) با کش صفحه سازگارند.
