# محدودیت‌ها و قابلیت‌های وابسته به افزونه پولی

- **Theme Builder** (هدر/فوتر/محصول/آرشیو با شرط نمایش) و **Dynamic Tags** فقط با **Elementor Pro**. بدون آن، هدر/فوتر/صفحات ووکامرس با قالب داخلی (قابل تنظیم از سفارشی‌ساز) نمایش داده می‌شوند و هدر/فوتر را می‌توان از یک قالب ذخیره‌شده Elementor انتخاب کرد.
- **علاقه‌مندی‌ها و مقایسه** با افزونه Samadi Core (یا YITH / TI برای علاقه‌مندی). بدون هیچ‌کدام، این دکمه‌ها نمایش داده نمی‌شوند.
- **پرسش و پاسخ محصول** نیازمند افزونه مربوط است.
- **فیلتر**: شمارنده کنار هر گزینه، تعداد محصولات آن گزینه در دسته جاری است (بدون احتساب سایر فیلترهای فعال). فیلتر ویژگی‌ها روی ویژگی‌های سراسری (Global Attributes) کار می‌کند، نه ویژگی‌های سفارشی تک‌محصول.
- **Cart/Checkout Blocks**: استایل شده‌اند ولی ساختار داخلی آن‌ها را React ووکامرس تعیین می‌کند؛ ویجت‌های سبد/تسویه Elementor Pro با صفحات شورت‌کدی سازگارترند.
- **نماد اعتماد / ساماندهی**: فقط کد رسمی صادرشده برای همین دامنه را در ابزارک «فوتر: نمادهای اعتماد» قرار دهید؛ قالب هیچ نماد یا اطلاعات تماسی تولید نمی‌کند.
- **ترجمه متن‌های ووکامرس/وردپرس** از بسته زبان فارسی رسمی آن‌ها می‌آید (زبان سایت = فارسی).
- **تاریخ شمسی** با ماژول تاریخ شمسی Samadi Core (یا افزونه‌ای مثل Parsi Date).
- **فونت ایران‌یکان** تجاری است و همراه قالب نیست؛ با مجوز، آن را بارگذاری و نامش را در سفارشی‌ساز وارد کنید. وزیرمتن (OFL) همراه قالب است.
